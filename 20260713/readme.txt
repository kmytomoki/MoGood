
MoGoodアプリケーションの概要：

食料品価格の高騰が続くなか、同じ食材でも容量やパック数の違いにより、本当に割安な商品をその場で判断することは難しい。本提案は、スーパーの棚をスマートフォンで撮影するだけで、AIが価格や内容量などを解析し、「100gあたり」などの共通単価に換算して比較を行い、最も安い商品を購入前に提示する買い物支援・食材管理アプリである。また、「できるだけ安く買いたい」「国産品を選びたい」「健康を重視したい」など、利用者が自然な言葉で要望を伝えると、LLMがその意図を理解し、価値観に合った商品を提案する。さらに、購入した食材の賞味期限をスマートフォンで読み取って管理し、期限の近い食材を活用したレシピを提案することで、家計の節約と家庭のフードロス削減を同時に実現する。

LLMによる実験：

・家庭の冷蔵庫にある「家庭食材リスト」を作成
・スーパーにある食材と価格の「スーパー食材リスト」を作成。「スーパー食材リスト」は容量やパック数にバリエーションがある。さらに産地や健康に関してもバリエーションがあるリストにする。
・「家庭食材リスト」と「スーパー食材リスト」を考慮し、個人がある料理を作るにあたって、その個人の好みに合った属性に応じて、何をスーパーで購入すれば良いかをアドバイスするプログラムを作成せよ。
・個人の好みとは、低価格重視、健康重心、家庭の食材をできるだけ効率的に消費するがある。


アルゴリズム版の実行方法
python3 mogood_advisor.py

2. ollama pull qwen3:8b （最初だけ）
