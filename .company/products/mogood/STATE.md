# プロダクト: MoGood

最終更新: 2026-08-17 / フェーズ: **Phase 0（検証）**

## 一行

冷蔵庫の在庫 → レシピ提案 → 買い物リスト → 店頭でのお得判定 → 消費計算 → 修正、という毎日の献立サイクルを1つのDBで回すスマホアプリ。

## MVP スコープ（6機能・`docs/instruction.md` §5）

1. 在庫管理（数量・賞味期限、期限順表示、カテゴリ別期限自動推定）
2. レシピ提案（在庫消化案＋好み寄り案を並べる。在庫縛りは強制しない）
3. 買い物リスト（不足食材のワンタップ追加、2〜5日分の計画からまとめ生成）
4. 店頭スキャン（商品名・容量・価格を読み取り、共通単価に換算、棚内比較＋購入履歴比較）
5. 消費計算（献立確定時にレシピ分量から自動で在庫を引き落とす）
6. 在庫修正（調理後のズレを管理画面から簡単修正）

## スコープ外

店舗間リアルタイム価格比較 / クラウドソース価格共有 / スマートグラス / 自前モデル学習 / 決済・電子レシート連携 / 栄養・カロリー計算
