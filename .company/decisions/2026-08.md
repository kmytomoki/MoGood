# CEO 意思決定ログ — 2026年8月

## 2026-08-17: AI-CEO Framework の導入

- **決定**: MoGood プロジェクトに AI-CEO Framework（JOINCLASS/ai-ceo-framework, MIT）を導入する
- **理由**: 部門ごとの役割分担・承認パイプライン・仮説検証ゲートを仕組みとして持ち込むため
- **範囲**: 15エージェント・5スキル・11部門すべてのファイルを配置

## 2026-08-18: 収益モデル再設計の体制（承認済み）

- **決定1**: `.claude/commands/ai-ceo/growth/` に `monetize` / `pricing` / `experiment` を登録する
  - **理由**: 収益モデルの主担当は `growth-agent`（定義に Pricing Optimization と monetize がある）だが、コマンドとして未登録だった
  - **登録しなかったもの**: `funnel` と `quick-win`。LP・アナリティクスデータが存在しないため、実行すると根拠のない数字を作る恐れがある。ユーザーがつくまで登録しない
- **決定2**: `cfo-agent` を**収益モデル再設計に限り一時起用**する（部門の休止は解除しない）
  - **理由**: 3ヵ年収支のシナリオ分析には財務予測の型が必要
  - **終了条件**: Phase 0 の API 原価実測を反映して `docs/事業プラン草案.md` §4 を更新した時点で完全休止へ戻す
- **決定3**: 収益モデルの検討順序を「① cfo（収支）→ ② cto（原価側の技術的当たり）→ ③ growth（課金境界・価格表示）→ ④ legal（広告・タイアップの表示義務）→ ⑤ validate-hypothesis」とする
  - **理由**: 数字と原価が出る前に価格設計を回すと、根拠のない価格が出る
- **成果物**: `20260818/収支再計算.md`（手順①の結果）
