## AI の使い方（守ること）

| タスク | 方針 |
|---|---|
| ラベル・値札の読み取り | 汎用VLMに画像を投げて構造化データを取得（YOLO等のパターン学習型は不向き） |
| **単価への換算** | **ルールベースで確実に計算する。AIに計算させない** |
| **消費量の計算** | **ルールベース**（レシピ分量 × 人数）。AIの役割は在庫アイテムとの**名寄せのみ** |
| 単位のばらつき・同種商品判定 | AIに任せる |
| 抽出値の検証 | **必ず検算・異常値チェックを挟む** |
| 賞味期限 | カテゴリ別標準日数の辞書。AIはカテゴリ分類のみ |
| レシピ提案 | LLMに在庫＋好み＋購買履歴＋献立計画を渡して生成。**キャッシュ前提**（原価の主戦場） |

## 禁止事項（`docs/instruction.md` §8）

- 単価・消費量の計算をLLMに丸投げしない
- レシートOCRを入力の主軸にしない
- 価格データを他ユーザーと共有・公開する設計にしない
- §6 の検証を飛ばして機能を作り込まない
- 基盤モデルの自作・ファインチューニングをMVPで始めない

## 非機能の目標

- スキャンのレイテンシ予算（合計5秒以内・Phase 0で実測）: 圧縮0.5s / アップロード0.5s / VLM 2〜3s / 検証・換算・整列0.5s / 描画0.5s
- Phase 1 から「在庫の更新頻度・修正頻度・スキャン成功率・所要秒数・原価」をイベントログで収集
