# ブランドガイドライン

最終更新: 2026-08-17

## 名称

- 表記: **MoGood**（フリガナ: モグッド）
- 「MoGood」の後は記号（ー等）ではなく**半角スペース1文字**で区切る（グランプリのタイトル字数・記号制限対策）
- 応募タイトル（推奨・25文字）: **MoGood 冷蔵庫から始める献立と買い物の自動化**
- WEB登録時のタイトルとシートのタイトルは**必ず一致**させる

## 一行紹介

冷蔵庫の在庫・献立・買い物リスト・店頭でのお得判定・調理後の在庫更新までを1つのループとして管理し、毎日の「把握して・考えて・選ぶ」ストレスをなくす食材管理アプリ。

## 訴求の柱（この順で語る）

1. **考えずに、回る** — 毎日の献立サイクルを AI が代わりに回す
2. **入力させない** — 買い物リストのワンタップ確定と消費量の自動計算で、手入力をほぼゼロにする
3. **買う前に分かる** — 棚の前で共通単価（100gあたり等）に換算してお得を提示
4. **使うほど馴染む** — 在庫履歴・買い物台帳・好み学習が貯まる

## トーン

- 日本語。結論を先に述べる。トレードオフを隠さない。
- 誇張しない。**未検証の数値を断定形で書かない**（「〜と試算している（仮置き）」と書く）。
- 生活者向けの言葉を使う（「単価換算エンジン」ではなく「100gあたりでどっちが安いか」）。

## 使ってはいけない表現

| NG | 理由 |
|---|---|
| 「最安保証」「どの店より安い」 | 店舗間比較はしない（確定事項5）。事実に反する |
| 「完璧に在庫を管理」「正確な記録」 | ズレ許容＋簡単修正が設計原則（確定事項4） |
| 「レシートを撮るだけ」 | レシートOCRは入力の主軸にしない（確定事項10） |
| 「独自AIを開発」「自社モデル」 | 既存VLM/LLM APIを使う（確定事項7）。虚偽になる |
| 「みんなの価格情報が集まる」 | 価格データは共有・公開しない（確定事項8） |
| 「食費が月◯円下がります」 | 効果は未検証。仮説であることを明示する |
